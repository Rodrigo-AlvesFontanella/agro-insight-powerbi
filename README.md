# Agro Insight — Map & Forecast

Precision-agriculture dashboard for a **fictional agribusiness company**,
mapping its farms and fields by crop type using ArcGIS Maps for Power BI
(lat/long points, sized by hectares), plus a statistical Forecast (Power BI's
native Analytics pane) projecting future fertilizer consumption from
historical trend and seasonality. All company, farmer and field data is
synthetic.

**Live case study:** https://claude.ai/code/artifact/d8c46e72-b3f1-4045-975e-3662bba4a87d#agro

## What's in this repo

- `agro_analytics.pbip` / `agro_analytics.Report/` /
  `agro_analytics.SemanticModel/` — the Power BI project in **PBIP format**
  (Microsoft's git-friendly source format): every measure, relationship and
  visual is a readable JSON/TMDL file, not a compiled binary.
- `data/` — the synthetic CSV data sources (farmers, fields, fertilizer
  consumption) and the Python script that generated them
  (`gerar_dataset_agro.py`).

## Notable techniques

- **ArcGIS Maps for Power BI** plotting 162 fields by lat/long, colored by
  crop, sized by hectares.
- **Native statistical Forecast** (Analytics pane) on the monthly fertilizer
  consumption trend, with a 95% confidence interval.
- A calculated `Stages`/snapshot pattern for point-in-time headcount-style
  measures across the dataset.

## Data

All data is synthetic, generated by `data/gerar_dataset_agro.py` — no real
farmer, farm or company data appears anywhere in this project.

## Opening this project

Requires Power BI Desktop with the PBIP preview feature enabled, plus the
ArcGIS Maps for Power BI visual (built into modern Power BI Desktop). The
Power Query source step points at an absolute path on the original
development machine — after cloning, repoint it to wherever you place the
`data/` folder locally (Power Query Editor → the `Source` step of each
table).
